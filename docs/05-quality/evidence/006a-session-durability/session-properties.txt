# The session layer's properties: bootstrap, currency, OTP call shapes,
# device-local sign-out, and ADR-009's persistence guarantee — the
# observed purge (read-back as the only proof), the durable
# re-authentication demand and its bootstrap consult, and the
# record-then-absorb write path.
#
# TWO SUITES, and the split is deliberate. In auth-provider the supabase
# client module is replaced by a double, which is what REVIEW-020 finding 1
# said could never observe the property: method spies cannot see a storage
# write. So foreground-refresh runs the REAL chunked adapter over a real
# in-memory keychain and produces the refused write by actually refusing
# one. The provider suite proves the wiring; the foreground-refresh suite
# proves the behaviour.
#
# No network call and no credential is involved in either.
