# ADR-003: Payment, purchase, entitlement, and billing-webhook logic changes are RED-lane items requiring explicit per-item approval

**Date:** 2026-08-18
**Status:** Accepted
**Deciders:** Ahmed (owner), on controller recommendation

> Immutable. Once committed, do not edit this file. To change the decision,
> write a new ADR and set this one's status to Superseded.

## Context

REVIEW-001 finding 1 exposed a contradiction between ADR-001's advisory-review
grouping and AGENTS.md's RED lane.

## Decision

Payment, purchase, entitlement, and billing-webhook logic changes are RED-lane
items requiring explicit per-item approval.

## Alternatives considered

| Option | Why not |
|---|---|
| Advisory-review-only | Rejected: RED lane guards the costliest failure class for minutes of owner time. |
